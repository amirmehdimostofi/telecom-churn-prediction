# churn_prediction_Classification
Churn prediction for a telecome company


## Project Overview
Churn prediction for telecome industry

## Objectives

- Clean and prepare the dataset
- Explore relationships between Call Detail Record (CDR) + CRM data base data and churn
- Build classification models: Logistic regreesion, KNN, Random Forest, SGB, SVM
- Evaluate model performance


## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Structure

- `classification.ipynb`: Main analysis notebook
- `data/`: Dataset or sample data
- `requirements.txt`: Required Python libraries

## Methodology

1. Data cleaning
2. Exploratory data analysis
3. Feature engineering
4. Train-test split
5. Model training
6. Model evaluation

## Model Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- F2 Score
